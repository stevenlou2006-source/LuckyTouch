## ⚠️ 重要提示：半成品 & 单人模式

- **单人模式**：当前版本仅支持单人游戏，多人同步功能尚未实现。
- **半成品状态**：核心运气积累和价格影响机制稳定，但**颜色刷新存在延迟**：抓取贵重物品后，需要**旋转物品（如鼠标右键）**才会触发光束颜色更新。非贵重物品（如武器）不受影响。

## 📖 概述

这是一个为《REPO》游戏设计的**单人**运气系统模组，**必须与“随机贵重物品的价格”模组搭配使用**。

### 核心机制
- 每次抓取贵重物品后，**价格的变化**会按比例影响你的“团队运气值”（目前单人模式即个人运气）。
- 运气值又会以乘数方式影响**下一次抓取的价格随机化结果**。
- **光束颜色**会随价格变化而改变：涨价变绿，跌价变红。但颜色不会立即更新，需要**旋转物品**才会看到变化。

### 与原模组的关联
- 复用原模组的**价格随机化逻辑**（倍率范围、黑白名单等）
- 新增**运气系统独立配置**（开关、积累比例、范围、颜色等）
- 两个模组的配置**各自独立，互不干扰**

## ✨ 功能特点

- 🎲 **运气值动态积累**：涨价增加运气，跌价减少运气
- ⚙️ **可配置参数**：积累比例、衰减率、单次变化上限、运气范围等
- 🎨 **光束颜色反馈**：高运气绿色，低运气红色（需旋转物品触发更新）
- 📋 **详细日志**：可开启详细日志观察运气变化过程
- 🧑‍🤝‍🧑 **单人限定**：仅限单人模式，多人同步后续版本考虑

## 📥 安装方法

### 自动安装（推荐）
1. 安装 [Thunderstore Mod Manager](https://www.overwolf.com/app/Thunderstore-Thunderstore_Mod_Manager) 或 [r2modman](https://thunderstore.io/package/ebkr/r2modman/)。
2. 确保已安装依赖：
   - **AdvancedREPO.Config**（配置同步框架）
   - **随机贵重物品的价格**（原模组）
3. 搜索 **LuckyTouch** 作者 **dyxc666** 并安装。

### 手动安装
1. 安装 [BepInEx 5](https://github.com/BepInEx/BepInEx/releases)。
2. 安装 **AdvancedREPO.Config** 和 **随机贵重物品的价格** 模组。
3. 将 `LuckyTouch.dll` 放入 `BepInEx/plugins/` 文件夹。

## ⚙️ 配置说明

配置文件位于：`BepInEx/config/LuckyTouch/LuckyTouch.cfg`  
如需修改，请直接编辑该文件（推荐使用支持 `.cfg` 的文本编辑器）。

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `启用运气系统` | 总开关 | true |
| `价格_积累比例` | 价格变化绝对值计入运气的比例 | 0.03 |
| `自然衰减比例` | 每次抓取后运气值向1.0衰减的比例 | 0.15 |
| `单次变化上限` | 每次运气值变化的最大绝对值 | 0.15 |
| `运气最小值` | 允许的最低运气值 | 0.2 |
| `运气最大值` | 允许的最高运气值 | 2.2 |
| `高运气颜色` | 涨价时抓取光束颜色 (十六进制) | #00FF00 |
| `低运气颜色` | 跌价时抓取光束颜色 (十六进制) | #FF0000 |
| `详细日志输出` | 输出核心运气变化数据 | false |

> **注意**：颜色反馈需要旋转物品才会更新，这是已知问题。

## 🎮 使用说明

1. **确保原模组已安装并配置好**（倍率范围等）
2. 进入游戏，抓取贵重物品：
   - 抓到高价 → 运气上升 → 下次更容易涨价
   - 抓到低价 → 运气下降 → 下次更容易跌价
3. 抓取后如需立即看到颜色变化，可**旋转物品（鼠标右键）**触发更新。
4. 开启“详细日志输出”可观察运气变化过程。
